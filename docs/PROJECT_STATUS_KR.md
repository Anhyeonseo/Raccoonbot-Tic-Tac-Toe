# 프로젝트 현재 상태

기준일: 2026-08-23

## 완료

- 참가자 선공, 각 3말 배치, 자유 이동 방식의 3목 규칙
- 승리, 3회 반복, 이동 10턴 제한 판정
- 즉시 승리는 항상 선택하고 나머지는 확률적으로 실수하는 AI
- 합성 흑백 체스판과 빨강/노랑 말 생성
- 네 모서리 원근 보정과 9칸 색상 판독
- 여러 프레임이 일치할 때만 보드 상태 확정
- 관측 전후 차이에서 사람의 배치 또는 이동 추론
- 가상 로봇과 안전한 hover/grasp 명령 순서
- 공식 `robomation.RaccoonBot` API 어댑터
- 로봇 결과가 카메라 예상과 일치할 때만 게임 상태 확정
- 클릭 가능한 데스크톱 부스 UI
- 현장 캘리브레이션, 합성 데이터, 사진 검사, 자세 검증 CLI
- A4 임시 보드와 임시 색상 말
- 단위·통합 테스트 43개

## 실제 장비 이후 진행

1. NVMe SSD 장착 및 Jetson 브링업
2. 카메라와 Mini Dongle+ 장치 확인
3. Jetson ARM64에서 공식 `robomation` 패키지 통신 확인
4. 실제 보드·말 제작 및 카메라 고정
5. 현장 조명에서 `config/vision.json` 생성
6. 9칸과 stock 3곳의 hover/grasp 자세 teaching
7. `config/robot_poses.json` 생성 및 저속 단일 이동 시험
8. 실시간 카메라·실제 로봇·부스 UI 통합
9. 오류 복구, 긴급 정지, 연속 30~50게임 시험
