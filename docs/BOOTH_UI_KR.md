# 노트북 브라우저 부스 UI 운영

## 실행 구조

게임, 카메라 판독, AI와 로봇 제어는 Jetson에서 실행한다. 노트북은 SSH 터널을
통해 브라우저 화면과 운영 입력만 담당한다. 화면의 보드 칸은 조작 버튼이 아니라
카메라가 확정한 실제 보드 상태다.

```text
노트북 http://127.0.0.1:8080
            │ SSH tunnel
Jetson 127.0.0.1:8080
  ├─ 게임 상태기와 AI
  ├─ 카메라 인식·재캘리브레이션
  └─ RaccoonBot 제어
```

## 연결과 실행

현장 기본 연결은 데이터 통신이 가능한 USB-C to USB-C 케이블이다. 노트북과
Jetson DevKit의 USB-C 포트를 연결하고 Jetson은 정식 전원 어댑터로 켠다.
Jetson의 USB Type-A 포트는 노트북 직결에 사용하지 않는다.

```bash
ssh hyper@192.168.55.1
RACCOONBOT_SSH_IDENTITY=/path/to/private-key bash scripts/run_booth_ui.sh
```

브라우저에서 `http://127.0.0.1:8080`을 연다. 행사장 Wi-Fi 주소가 바뀌어도
USB 장치망 주소 `192.168.55.1`은 유지된다. 개발실 Wi-Fi를 쓰려면 다음처럼
대상만 바꾼다.

```bash
RACCOONBOT_JETSON_TARGET=hyper@192.168.35.236 \
RACCOONBOT_SSH_IDENTITY=/path/to/private-key \
bash scripts/run_booth_ui.sh
```

기본 AI는 초등학생 체험용 `쉬움`이다. 즉시 이기는 수는 항상 두지만, 방어와 좋은
수는 일부러 놓칠 수 있다. 더 어려운 동작 확인에는 아래 옵션을 쓴다.

```bash
RACCOONBOT_DIFFICULTY=normal \
RACCOONBOT_SSH_IDENTITY=/path/to/private-key \
bash scripts/run_booth_ui.sh
```

카메라 영상 노드나 Mini Dongle+ 직렬 경로가 현재 장비와 다르면 실행 전에 실제
장치를 확인하고 다음처럼 지정한다.

```bash
RACCOONBOT_CAMERA_DEVICE=/dev/video2 \
RACCOONBOT_ROBOT_PORT=/dev/serial/by-id/<mini-dongle-id> \
RACCOONBOT_SSH_IDENTITY=/path/to/private-key \
bash scripts/run_booth_ui.sh
```

카메라 번호는 `v4l2-ctl --list-devices`, 직렬 경로는
`find /dev/serial/by-id -maxdepth 1 -type l`로 확인한다.

## 게임 운영

1. 빈 보드, stock의 노란 말 3개, 작업 영역 밖의 사람 손을 확인한다.
2. `새 게임`을 누른다.
3. `내 차례`가 표시된 뒤 빨간 말을 놓거나 옮긴다.
4. 손을 완전히 뺀 뒤 `내 차례 완료`를 누른다. 키보드 `Enter`도 같은 입력이다.
5. `라쿤봇 차례`와 `결과 확인` 동안 작업 영역에 손을 넣지 않는다.
6. 인식 오류가 표시되면 물리 보드를 바로잡고 `다시 확인`을 누른다.
7. 게임이 끝나면 말을 회수하고 `화면 초기화` 후 다음 참가자를 받는다.

별도 굿즈 버튼은 사용하지 않는다.

## 운영 복구

- `다시 확인`: 손이나 흔들린 말 때문에 인식이 실패했을 때 현재 상태를 다시 촬영한다.
- `게임 중단`: 현재 관절 이동이 끝난 뒤 다음 이동·그리퍼 명령 전에 게임을 멈춘다.
- `화면 초기화`: 종료·중단·오류 상태를 시작 대기로 되돌린다. 로봇은 움직이지 않는다.
- 새 게임 재시작: 보드를 완전히 비우고 노란 말 3개를 stock에 복원한 뒤 시작한다.

`게임 중단`은 즉시 모터 전원을 끊는 물리 비상정지가 아니다. 충돌 위험이나 사람
접근처럼 즉시 정지가 필요한 상황에는 작업 영역 접근 금지와 현장의 물리 전원 차단
절차를 따른다.

## 현장 재캘리브레이션

카메라·보드 거치가 달라졌거나 조명이 크게 바뀌었을 때만 수행한다. 게임 실행
중에는 캘리브레이션을 시작할 수 없다.

로봇팔이 보드를 가리면 먼저 게임 탭에서 빈 판으로 `새 게임`을 시작한다. 로봇이
관찰 자세로 복귀해 `내 차례`가 표시되면 `게임 중단` 후 `화면 초기화`를 누르고
캘리브레이션 탭으로 이동한다.

1. 보드의 서로 다른 칸에 빨간 말과 노란 말을 하나씩 놓는다.
2. `현장 캘리브레이션` 탭에서 `카메라 촬영`을 누른다.
3. 화면 안내 순서대로 좌상단, 우상단, 우하단, 좌하단을 클릭한다.
4. 빨간 말 중앙과 노란 말 중앙을 클릭한다.
5. `미리보기 생성` 후 보드 방향, 1~9 칸, 색 비율을 확인한다.
6. 틀렸다면 `점 다시 선택`으로 고친다.
7. 결과가 맞을 때만 `설정 저장`을 누른다.

저장 시 기존 `config/vision.json`은 같은 폴더의 타임스탬프 백업 파일로 보존된다.
미리보기만으로는 설정이 바뀌지 않는다. 저장 후 게임 탭에서 빈 판 검사를 거쳐
한 게임을 진행한다.

## 사용자 최종 자가검증

1. 행사에 사용할 노트북과 USB-C 케이블로 `192.168.55.1` SSH 접속을 확인한다.
2. 부스 UI를 켜고 재캘리브레이션 미리보기까지 확인한다. 설치가 그대로면 저장은 생략한다.
3. 쉬움 AI로 빈 판 한 게임을 완주한다.
4. 사람 수를 일부러 잘못 둔 뒤 `다시 확인` 복구를 한 번 확인한다.
5. 사람이 기다리는 상태에서 `게임 중단`과 `화면 초기화`를 한 번 확인한다.
6. 다시 새 게임을 시작할 수 있으면 운영 검증을 마친다.

종료할 때는 실행 터미널에서 `Ctrl+C`를 한 번 누르고 서버와 SSH 터널의 종료
메시지를 기다린다.
