# 부스 운영 안내

이 문서는 설치가 끝난 장비로 게임을 진행하고 현장에서 복구하는 절차입니다.
설치·SSH 문제는 [INSTALLATION_KR.md](INSTALLATION_KR.md)를 확인하세요.

## 1. 운영 전 점검

1. 로봇, 보드와 카메라 거치대가 teaching 및 캘리브레이션 당시 위치에 고정됐는지
   확인합니다.
2. 9개 셀을 비우고 노란 말 3개를 stock 1~3에 하나씩 둡니다.
3. 로봇 이동 경로와 비상 전원 차단 위치를 확보합니다.
4. Jetson에 카메라와 Mini Dongle+를 연결하고 라쿤봇 전원을 켭니다.
5. 운영 노트북에서 UI를 실행합니다.

```bash
cd Raccoonbot-Vision-Three-in-a-row
RACCOONBOT_SSH_IDENTITY=/path/to/private-key \
bash scripts/run_booth_ui.sh
```

브라우저에서 <http://127.0.0.1:8080>을 엽니다. 터미널은 서버 로그와 종료를 위해
행사 중 계속 열어 둡니다.

## 2. 게임 진행

1. `새 게임`을 누르면 라쿤봇이 `transit → home_high → home` 관찰 자세로 이동하고
   빈 보드를 확인합니다.
2. 참가자가 빨강 말 하나를 놓거나 옮긴 뒤 보드에서 손을 뺍니다.
3. 운영자가 `내 차례 완료`를 누릅니다. 게임 화면에서 Enter 키도 같은 기능입니다.
4. 잘못된 수로 표시되면 UI 안내에 따라 말을 고친 뒤 다시 제출합니다.
5. 라쿤봇이 움직이는 동안 보드에 손을 넣지 않습니다.
6. 승리·패배·무승부가 표시되면 말을 치우고 `화면 초기화` 후 새 게임을 시작합니다.

쉬움 AI는 방어와 최선 수를 확률적으로 생략해 어린이도 이길 기회를 만듭니다.
보통 AI가 필요하면 서버 시작 전에 `RACCOONBOT_DIFFICULTY=normal`을 지정합니다.

## 3. 운영 UI 복구 기능

| 기능 | 사용 시점 | 동작 |
|---|---|---|
| `내 차례 완료` | 참가자가 수를 둔 뒤 | 안정화 프레임으로 보드 변화를 검사 |
| `게임 중단` | 인식 오류, 말 이탈, 진행 취소 | 현재 관절 이동 후 다음 명령 전에 중단 |
| `화면 초기화` | 중단·오류·종료 화면 정리 | UI 상태를 새 게임 대기로 복원 |
| `현장 캘리브레이션` | 카메라나 보드 위치 변경 | 보드 네 모서리를 다시 저장 |

`게임 중단`은 물리 비상정지가 아닙니다. 충돌, 기구 걸림 또는 사람 접근에는 UI를
기다리지 말고 현장 전원 차단 절차를 사용합니다.

일반 오류 복구 순서:

1. `게임 중단`을 누르고 UI가 중단 상태가 될 때까지 기다립니다.
2. 보드에서 모든 말을 치우고 노란 말 3개를 stock에 복원합니다.
3. 넘어진 말, 밀린 보드, 느슨해진 거치대와 케이블을 확인합니다.
4. `화면 초기화`를 누르고 새 게임을 시작합니다.
5. 같은 문제가 반복되면 터미널 로그와 `work/game-captures/`의 이미지를 확인합니다.

## 4. 현장 카메라 재캘리브레이션

카메라나 보드의 상대 위치가 바뀌었거나, 워프 영상에서 셀이 잘리거나, 실제 말이
다른 칸으로 판정될 때 수행합니다. 이 도구는 **보드 네 모서리만 갱신하며 검증된
빨강·노랑 HSV 설정은 유지**합니다.

1. 게임을 중단하고 화면 초기화까지 완료합니다.
2. 보드 위 말을 모두 치우고 로봇 이동 경로와 주변에서 손을 뺍니다.
3. `현장 캘리브레이션` 탭에서 `관찰 자세로 이동하고 촬영`을 누릅니다.
4. 로봇은 `transit → home_high → home`으로 이동합니다. 연결이 유지된 실제
   `home` 상태에서 사진을 찍은 뒤에만 연결을 해제합니다.
5. 촬영 이미지에서 흑백 보드 **바깥 테두리**의 좌상단, 우상단, 우하단, 좌하단을
   순서대로 클릭합니다.
6. `미리보기 생성`을 누르고 워프된 정사각형의 전체 테두리, 위쪽 행, 9개 격자가
   모두 포함됐는지 확인합니다.
7. 빈 보드는 9칸 모두 `empty`로 나와야 합니다. 이상하면 저장하지 말고 점을 다시
   선택합니다.
8. 이상이 없을 때만 `검증값 저장 확정`을 누릅니다. 기존 `vision.json`은 시간 표시가
   붙은 파일로 자동 백업됩니다.

상단 셀이나 바깥 테두리가 잘린 미리보기는 저장하면 안 됩니다. 이전 인식 오류는
상단 모서리를 실제 보드보다 아래로 선택해 1~3번 셀이 잘린 것이 원인이었습니다.

현재 검증한 판정 기본값은 셀 가장자리 15% 제외, 해당 색상 픽셀 4% 이상입니다.
말을 셀 중앙에서 조금 벗어나게 놓아도 판정하되, 보드 밖이나 셀 경계에 걸치게 두지
않습니다.

## 5. 자세와 운반 점검

카메라와 보드만 이동했다면 로봇 자세를 다시 teaching하지 않습니다. 보드나 로봇의
상대 위치, 말 높이·지름이 바뀌었다면 9개 셀과 stock 자세를 다시 확인합니다.
자세 저장 절차는 [config/README_KR.md](../config/README_KR.md)에 있습니다.

말 하나로 전체 셀의 집기·놓기를 확인하는 최종 시험:

```bash
raccoonbot-validate-poses config/robot_poses.json
raccoonbot-smoke-cell-sweep config/robot_poses.json --confirm-motion
```

1번에 말 하나를 놓고 나머지 칸을 비운 뒤 실행합니다. 카메라는 사용하지 않으며,
말을 `1→2→…→9`로 옮기는 전 과정을 운영자가 직접 확인합니다.

## 6. 종료

1. 게임이 움직이는 중이 아니도록 확인합니다.
2. UI 서버를 실행한 노트북 터미널에서 Ctrl+C를 누릅니다.
3. `로봇 정지와 연결 해제` 로그 뒤 SSH가 끝날 때까지 기다립니다.
4. 라쿤봇, Jetson과 주변 장비의 전원을 순서대로 끕니다.

## 7. 행사 당일 최소 체크리스트

- USB-C 직결 주소 `192.168.55.1`로 SSH 접속
- UI 열림, 카메라·Mini Dongle+ 장치 확인
- 빈 보드 9칸 `empty` 확인
- 빨강·노랑 말을 중앙과 가장자리 셀에서 각각 확인
- 새 게임 관찰 자세와 한 번의 집기·놓기 확인
- 운영자에게 중단 버튼과 물리 전원 차단 위치 공유
